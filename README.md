# 🔢 Búsqueda del Máximo con Divide y Vencerás

Mini proyecto desarrollado en JavaScript como parte del módulo de **Divide y Vencerás de DEV.F**.

## 📌 Descripción

El programa permite registrar una lista de números y encontrar el valor máximo utilizando el algoritmo Divide and Conquer (Divide y Vencerás).

## ⚙️ Funcionalidades

- Registrar números mediante `prompt()`.
- Almacenar los números en un arreglo.
- Dividir el arreglo en dos mitades.
- Buscar recursivamente el máximo de cada mitad.
- Comparar los resultados y mostrar el número mayor.

## 💻 Tecnologías

- JavaScript
- HTML5

## 🎯 Objetivo

Practicar el enfoque Divide y Vencerás para resolver problemas mediante recursión, dividiendo un arreglo en subproblemas más pequeños y combinando sus resultados para encontrar el valor máximo.
